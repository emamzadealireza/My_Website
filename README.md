## اجرا و پیش‌نمایش

فایل `index.html` را دابل‌کلیک کنید، یا در پوشه‌ی پروژه اجرا کنید:

```
python -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

- **متن‌ها و آمار:** مستقیم در `index.html`. برای تغییر «نوار آمار» بخش `QUICK FACTS` را ببینید.

## انتشار روی dremamzade.ir

هر یک از این روش‌ها کافی است:

- **Netlify / Vercel / Cloudflare Pages:** پوشه را drag & drop کنید (یا مخزن GitHub را وصل کنید) و در تنظیمات Domains دامنه را اضافه کنید؛ رکوردهای DNS را همان سرویس می‌دهد.
- **هاست ایرانی / cPanel:** محتوای پوشه را در `public_html` آپلود کنید.
- **GitHub Pages:** مخزن را push کنید، در Settings → Pages شاخه‌ی `main` را انتخاب کنید و DNS دامنه را تنظیم کنید.

پس از اتصال دامنه، HTTPS را فعال کنید (در سرویس‌های بالا خودکار است).
