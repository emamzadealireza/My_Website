# وب‌سایت شخصی — دکتر علیرضا امام‌زاده

سایت تک‌صفحه‌ای و استاتیک برای دامنه‌ی `dremamzade.ir`؛ فقط HTML + CSS + JavaScript، بدون بیلد، بدون دیتابیس و بدون وابستگی به CDN (فونت‌ها و آیکن‌ها همه داخل پروژه هستند).

## ساختار صفحه

| بخش | توضیح |
| --- | --- |
| هدر | نام، تخصص، منوی چسبان و دکمه‌ی «دریافت رزومه» |
| Hero | عکس پروفایل + معرفی کوتاه + ۴ نکته‌ی کلیدی رزومه + دکمه‌ها |
| نوار آمار | رتبه ۳ بورد، ۲ مدال طلا، ۲ مقاله، ۵+ سال تجربه |
| خدمات | معاینات طب کار، تناسب شغلی، ارگونومی و بیماری‌های شغلی، مشاوره و آموزش |
| رزومه | خلاصه‌ی حرفه‌ای + کارت دانلود PDF (Google Drive) |
| ارتباط | ایمیل، تلفن، تلگرام، واتساپ، لینکدین، بله، ایتا |
| فوتر | نام، سال جاری، بازگشت به بالا |

## اجرا و پیش‌نمایش

فایل `index.html` را دابل‌کلیک کنید، یا در پوشه‌ی پروژه اجرا کنید:

```
python -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

## ویرایش محتوا

- **متن‌ها و آمار:** مستقیم در `index.html`. برای تغییر «نوار آمار» بخش `QUICK FACTS` را ببینید.
- **رنگ‌ها و فونت:** متغیرهای ابتدای `styles.css`.
- **عکس:** فایل جدید را با نام `profile.jpg` جای فایل فعلی در `assets` بگذارید (نسبت ۴:۵، عرض ۸۰۰–۱۰۰۰ پیکسل).
- **رزومه:** لینک Google Drive در سه جا تکرار شده است (`cta` هدر، دکمه‌ی Hero، کارت رزومه). برای تغییر، آدرس جدید را جای
  `https://drive.google.com/file/d/1tsNaC4YBw6U5CYJLQnwPGcks0WJE8WxO/view?usp=sharing` بگذارید.

(اختیاری) چهار رکورد AAAA برای IPv6: `2606:50c0:8000::153`، `2606:50c0:8001::153`، `2606:50c0:8002::153`، `2606:50c0:8003::153`

پس از فعال‌شدن DNS، گواهی HTTPS (Let's Encrypt) به‌صورت خودکار توسط GitHub صادر می‌شود؛ سپس در **Settings → Pages → Enforce HTTPS** را روشن کنید (اگر فعال نشد، چند دقیقه صبر کنید و دوباره امتحان کنید).
